# VPRS Coordinate System & Pose Conventions

This document validates and formally defines the coordinate system, units, and output format generated by the Visual Pose Regression System (VPRS).

## 1. Units
- **Position**: All positional coordinates (X, Y, Z) are in **meters**.

## 2. Quaternion Representation
- **Order**: The system outputs quaternions in the order **[qx, qy, qz, qw]**.
- **Normalization**: The output quaternion is strictly normalized to a unit quaternion (magnitude = 1) at the end of the neural network's forward pass using L2 normalization (`F.normalize(..., p=2, dim=1)`).
- **Direction**: The quaternion represents the rotation **from the Camera Frame to the World Frame** (camera-to-world rotation).

## 3. Coordinate Frames

### World Frame (7-Scenes Environment)
The global reference frame in which the neural network predicts the position and orientation. Based on the 7-Scenes dataset generation (via KinectFusion):
- **+X** = Right/Left (Horizontal plane)
- **+Y** = Vertical axis (Gravity axis, typically Up/Down)
- **+Z** = Forward/Backward (Horizontal plane)
*(Note: The 2D top-down map trajectory is plotted using the X and Z axes, confirming Y is the vertical axis).*

### Camera Frame (OpenCV / Kinect Convention)
The local reference frame of the monocular camera sensor (XIAO ESP32S3).
- **+X** = Pointing to the **Right** of the image
- **+Y** = Pointing **Down** (towards the bottom of the image)
- **+Z** = Pointing **Forward** (along the optical axis into the scene)

### Drone Body Frame (Pending Integration)
When adapting this vision system to the drone's flight controller, you must map the Camera Frame to the standard flight controller body frame (e.g., MAVLink uses FRD, ROS uses FLU). 

Assuming a forward-facing camera mounted upright on the drone, the mapping from **Camera Frame (CV)** to **Drone Body Frame (FRD - Forward, Right, Down)** is:
- **CV +Z (Forward)** => **Drone +X (Forward)**
- **CV +X (Right)** => **Drone +Y (Right)**
- **CV +Y (Down)** => **Drone +Z (Down)**

## 4. Output Summary
A single inference returns a 7-element vector:
`[X, Y, Z, qx, qy, qz, qw]`
Where `X, Y, Z` represents the absolute position of the camera in the 7-Scenes world frame (in meters), and `qx, qy, qz, qw` is the unit quaternion describing the camera's orientation relative to that world frame.
